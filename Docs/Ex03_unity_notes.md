# Exercise 3, rasterised half: Nisse product photo in Unity URP

Built with Claude Code.

## What was built and why
The catalogue asks for a product photo of the scanned object made two ways, once with a ray-tracing tool and once in Unity or Unreal. The Cycles half is in `Docs/Ex03_blender_notes.md`. This half is the scene `Assets/Scenes/Ex03_Lighting.unity`, generated by `RtcgPart2.BuildEx03` in `Assets/Editor/RtcgPart2.cs` and rendered headless to PNG. The rig copies the Blender three-point setup (positions scaled by 3.33, because Nisse is 0.30 m in Blender and 1 unit in Unity) so the two images can be compared fairly.

Outputs in `Captures/Ex03_Unity/`: `nisse_unity_product.png` (hero, 1920x1080), `comparison_blender_vs_unity.png`, the build-up images and `sheet_buildup.png`, the light-type images and `sheet_light_types.png`, shadow and tone-mapping images and `sheet_shadow_tonemap.png`.

## Setup and key parameters
- Pipeline: URP, colour grading mode set to High Dynamic Range and additional lights set to Per Pixel (the project asset had Per Vertex, which cannot cast spot or point shadows). Camera allows HDR, SMAA high.
- Camera: physical camera, 85 mm, 36 x 20.25 mm sensor, DoF in Bokeh mode, f/8, focus 5 m.
- Key: spot, warm, intensity 42, 38 degrees, soft shadows. Fill: point, cool, intensity 7, no shadow. Rim: spot, white, intensity 45, 28 degrees, soft shadows, behind the object. Backdrop wash: spot, intensity 28, no shadow. Overhead: directional, intensity 0.35, soft shadows.
- Environment: a hand-made HDR cubemap (dark gradient plus three softboxes in the key, fill and rim directions) used for ambient light and reflections. This stands in for the area-light softboxes of the Blender scene.
- Post: Neutral tone mapping, post exposure +0.3, contrast 6, bloom threshold 1.0 intensity 0.15, vignette 0.15.
- Backdrop: a generated cyclorama mesh so there is no horizon line.

## Differences against the Cycles image (viewed side by side)
- Global illumination: Cycles bounces light off the backdrop, so the floor and the lower body pick up a faint bounce and the whole image looks evenly lit. Unity has no real-time indirect light here. The cubemap ambient term replaces it and is the same everywhere, so it does not react to the object.
- Shadows: Cycles has a faint, very soft contact shadow from large area lights. Unity uses shadow maps from spot and directional lights, so the cast shadow is longer and has a harder edge even with soft shadows enabled. Filtering blurs it by a fixed amount, not by the distance to the occluder as a real penumbra does.
- Area lights: URP supports area lights only when baked, so none are used in real time. The softboxes are emulated by the cubemap. The catalogue wants directional, point and area light experiments, so the area light part is covered by Blender and the Unity half uses directional, point and spot.
- Reflections: Cycles reflects the actual scene. Unity reflects only the cubemap, so the floor cannot reflect Nisse.
- Look: Unity renders slightly darker and cooler on the backdrop (grey 0.5 with Neutral tone mapping against AgX in Blender). The texture detail on the hat and beard is comparable in both.
- Cost: Cycles took about 9 s for 384 samples plus denoising. Unity renders the frame in a few milliseconds, which is the reason the approximations exist.

## Lecture terms to be able to explain
- Rasterisation versus path tracing, local versus global illumination (radiometryphotometry.pdf, "local vs. global illumination").
- Radiometry and photometry: radiance (W per m2 per sr, what the camera measures), irradiance (W per m2, light arriving at a surface), luminance in cd per m2 and illuminance in lux.
- BRDF: how much light from one direction leaves in another. Unity Lit uses a microfacet model (smoothness is one minus roughness).
- Three-point lighting: key, fill (sets the contrast ratio), rim (separates the silhouette).
- Point, spot, directional light: inverse-square falloff for point and spot, none for directional (sun at infinity).
- Shadow maps, depth bias and normal bias (the cause of shadow acne and peter-panning), shadow filtering.
- Image-based lighting: a cubemap used as ambient and reflection source.
- High dynamic range, tone mapping (None, Neutral and ACES compared in `sheet_shadow_tonemap.png`), exposure.
